THE PIPELINE

How MailGuard AI Works

From raw email text to a final classification, the system follows a simple machine learning pipeline.

01
INPUT

Email Text

The user submits an email message through the MailGuard AI web interface.

02
FEATURE EXTRACTION

TF-IDF Vectorization

The email text is converted into numerical features using Term Frequency-Inverse Document Frequency. The system considers unigrams and bigrams.

03
CLASSIFICATION

Complement Naive Bayes

The trained Complement Naive Bayes classifier evaluates the TF-IDF features and determines the most likely class.

04
OUTPUT

Spam or Legitimate

The system displays the predicted class along with the model's probability-based score.
